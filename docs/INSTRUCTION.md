# 操作指南

## 页面与账号

| 入口 | 用途 |
| --- | --- |
| 首页 `/` | 社区介绍、风景、精选成员、联系方式、FAQ 与博客文章 |
| 小镇档案 `/history` | 全部成员、图片与完整历史 |
| 小镇地图 `/map` | 建筑项目、范围与建造者 |
| 个人账号 `/account` | 用户名登录、修改个人资料与密码 |
| 楹雾私域 `/admin` | 管理后台，入口位于页脚 |

新账号由管理创建，不开放自助注册或 QQ 验证。首次登录需修改临时密码并确认。首页 QQ 群按钮复制号码，KOOK 打开频道。页脚左侧为 GitHub、Bilibili，中间的 SuperSam 手写签名打开 `https://blog.moesam.com/`，右侧为个人资料和后台入口。

## 权限

| 能力 | 游客（未登录） | 成员 | 管理 |
| --- | --- | --- | --- |
| 首页、档案、公开地图与项目详情 | ✓ | ✓ | ✓ |
| 创建、编辑、删除自己的项目 | — | ✓ | ✓ |
| 管理全部项目、上传／替换／删除地图 | — | — | ✓ |
| 内容、媒体、账号与统计后台 | — | — | ✓ |

## 地图项目

1. 在左上角切换地图。底图一个像素代表一个游戏方块，`16×16` 像素为一个区块，北方固定朝上。
2. 登录成员选择点选、矩形或画笔，选中区块后填写项目名、单人建造者的 Minecraft ID、介绍和颜色并保存。
3. 同一项目中上下左右相邻的区块自动连成区域；不同项目不能重叠。不连续的区域可以属于同一项目。
4. 侧栏直接展示项目，可分页并定位项目。悬浮查看摘要，点击项目（手机直接触摸）查看完整详情；具有权限时通过独立编辑按钮修改。
5. 管理可编辑、删除全部项目，转移项目的管理账号，并上传、替换、删除地图。建造者名称是展示资料，不代表后台账号权限。

项目没有状态或单独隐藏开关，公开地图上的项目全部展示。删除项目才会释放其区块。地图数据完整读取后才展示与开放编辑；加载失败用重试恢复。

地图上传小于 50 MiB，同时受像素总量、边长及切片数量上限约束；过大的图片需先裁剪或缩小。配置见 `server/maps/mapTilePipeline.ts`。

## 内容与媒体后台

- **语言与文案**：编辑中文／英文覆盖内容后保存。恢复默认文案会清除自定义覆盖。
- **成员管理**：维护主要成员、小镇成员、友好组织；支持游戏 ID 子串搜索（忽略大小写、首尾空格）与分类组合筛选。筛选时暂停排序，保存仍包含隐藏成员；新增会清除筛选。清除筛选后可拖动或使用上下按钮排序。最多选择 4 名成员在首页展示，可填写人物介绍。
- **历史管理**：维护日期、标题、正文和配图，排序后保存；完整历史只在档案页展示。成员、历史和 FAQ 保存会校验编辑版本，冲突时重新加载并合并修改，不覆盖其他管理的更新。
- **媒体管理**：上传图片或导入 Bilibili 视频，编辑备注、展示位置、布局、可见性和顺序。删除媒体需确认；写入期间暂时禁用编辑、排序和后台切页，完成后自动恢复。
- **FAQ**：编辑问题、答案与可见性；前台支持键盘操作及同时展开多个问题。
- **账号管理**：以用户名、临时密码和成员／管理角色创建账号；可将成员升为管理、重置临时密码或删除账号。管理角色不可在此降级，最后一位管理不可删除。
- **个人资料**：修改用户名与密码；密码留空表示不修改，不提供内部登录邮箱编辑。
- **网页数据**：切换每日总浏览／登录用户浏览、查看匿名访问统计与地图操作日志。

图片位置中，`其他` 仅保留在媒体库，不进入公共页面；退役的地图头图归入此类，文件仍保留；视频可放故事、画廊、历史及其他分类。图片备注在悬浮或聚焦时展示，Bilibili 仅在主动播放后加载播放器。

上传图片需要 Fastify 在线。系统保留原图并自动生成 1080p、720p 高质量 WebP，不用自行压缩；小图不会放大，图片比例不变。首页与档案头图用 1080p，其余用 720p，改分类后自动选择对应版本。删除媒体时原图与展示版本一起进入清理队列。首页头图预加载缓存最多约 30 秒。

删除账号时，其项目和媒体会转交管理，不删除公共媒体。Auth 清理未完成时明确提示等待重试；可从 API 日志检查失败原因，不要手工删除数据库底层记录。

首页与档案右侧目录随当前章节变化，只让当前或聚焦项发光；无框提示文字从右向左弹出，手机使用折叠菜单。首页天数按北京时间从 2020 年 7 月 6 日计算，使用 Georgia 粗体数字，首次进入视野计数 1.2 秒。风景照片全部参与随机流动，刷新后变化，返回首页保持布局；档案照片仍使用后台顺序。

首页自动展示 SamsBlog 最新一篇已发布文章，新增、修改和删除均在博客后台完成，无需在小镇后台重复维护。文章独立加载，点击标题、封面或“阅读文章”打开原文；同步失败可重试，不影响其他区块。

## 日常开发

```bash
pnpm dev:web     # 只启动前端
pnpm api:dev     # 只启动 API
pnpm check      # 类型检查并编译 API
pnpm lint
pnpm exec vitest run src/features/atlas/data/mapRepository.test.ts
```

`.env` 配置变更需重启开发服务；生产 `VITE_*` 变更需重新构建前端。界面颜色与动效入口见 [架构与审美](ARCHITECTURE.md)。
